合规与风险：劳务派遣、灵活用工、招聘平台的法律要点
人力资源平台涉及劳动法、税务、个人信息保护，合规是生命线。本文从资质、劳动、税务、隐私、资金五个维度展开。

一、资质

劳务派遣：《劳务派遣经营许可证》。人力资源服务：《人力资源服务许可证》。灵活用工：委托代征资质或对接有资质方。ICP备案、ICP许可证。小程序认证。支付商户号。

二、劳动合规

劳务派遣：派遣比例不超10%，同工同酬，社保缴纳。灵活用工：承揽关系而非劳动关系，避免事实劳动关系。电子合同。工伤处理。离职管理。

三、税务合规

灵活用工个税代扣。委托代征。发票开具：增值税专票/普票。完税证明。避免虚开发票。劳务派遣差额纳税。企业所得税。

四、个人信息保护

《个人信息保护法》。收集简历、身份证、银行卡需明示同意。最小必要。删除权。更正权。数据境内存储。等级保护。日志留存6个月。

五、资金合规

银行存管。避免二清。支付分账。提现资质。反洗钱。发票流、资金流、合同流三流合一。

六、技术安全

HTTPS、JWT、防SQL注入、XSS、CSRF。敏感脱敏。权限分级。操作日志。数据库备份。风控。

七、总结

人力资源平台合规要求高。源码搭建时需内置合规功能：实名认证、电子合同、发票、存管。运营方需咨询法律顾问，建立审核制度。
